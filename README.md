# Interview Prep

A comprehensive collection of study materials, code snippets, and projects designed to master full-stack development and ace technical interviews. This repository is organized into distinct modules covering backend development, database management, and frontend technologies.

## 🚀 Modules Overview

### 1. Backend Development (`/backend`)
Focuses on building scalable, type-safe, and efficient server-side applications.
*   **Node.js**: Core runtime architecture, event loop, file system, streams, and asynchronous programming concepts.
*   **Express.js**: RESTful API design, routing, custom middleware implementation, error handling, and security best practices.
*   **TypeScript**: Static typing, interfaces, generics, advanced types, and configuration for Node/Express ecosystems.

### 2. Databases & ORMs (`/databases`)
Covers relational and non-relational database management, data modeling, and Object-Relational Mapping tools.
*   **MongoDB & Mongoose**: NoSQL document modeling, schemas, validations, aggregations, and indexing.
*   **PostgreSQL**: Relational database fundamentals, complex joins, indexing, query optimization, and ACID transactions.
*   **Prisma**: Next-generation TypeScript ORM, schema migrations, type-safe database queries, and relations management.

### 3. Frontend Development (`/frontend`)
Contains core client-side concepts, UI architectures, and modern styling solutions.
*   **HTML & CSS**: Semantic markup, DOM structure, Flexbox, CSS Grid, and responsive design fundamentals.
*   **JavaScript**: ES6+ features, closures, promises, async/await, event bubbling/capturing, and prototype inheritance.
*   **Tailwind CSS**: Utility-first styling workflows, custom configurations, and rapid UI prototyping.

### 4. Advanced SQL (`/learn sql postgresql`)
Dedicated space for deep-diving into raw SQL scripting, performance tuning, and database administration drills specific to PostgreSQL.

## 🛠️ Getting Started

### Prerequisites
Ensure you have the following environments installed locally:
*   [Node.js](https://nodejs.org) (v18+ recommended)
*   [PostgreSQL](https://postgresql.org)
*   [MongoDB Community Server](https://mongodb.com)

### Clone the Repository
```bash
git clone https://github.com
cd interview-prep
```

### Running a Specific Topic
Navigate to any individual folder to explore its specific implementation files or specialized readmes:
```bash
cd backend/typescript
# Follow the local README instructions inside the subdirectory
```

## 📝 Key Interview Topics Covered
*   **System Design:** Designing scalable APIs, selecting SQL vs. NoSQL databases, and database normalization.
*   **Asynchronous JavaScript:** Managing race conditions, event loop blockages, and efficient microtask queues.
*   **Type Safety:** Eliminating runtime errors using TypeScript configurations.
*   **Database Optimization:** Writing efficient queries using Prisma and debugging slow PostgreSQL queries.
